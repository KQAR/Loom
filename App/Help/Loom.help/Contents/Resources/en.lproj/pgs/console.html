Loom Help

The menu-bar console

The console is for configuring and controlling Loom, not for reading traffic — that is the main window's job. It is laid out in bands, and what lands in which band comes down to one question: can this thing's state be read off a colour?

Header

  • The dot — green while recording, yellow when the proxy is up but recording is paused, grey when the proxy is off.
  • The address — where to point clients. It reads 127.0.0.1 normally and this Mac's LAN address while device capture is on. Click it in the main window's toolbar to change the port.
  • The key glyph — the privileged helper (below).
  • The switch — the proxy itself, on or off.

The four tiles

Each is one boolean, and the tint is the state.

TileWhat it switches
SystemRoutes the whole Mac through Loom, and blocks QUIC so browsers stay visible.
HTTPSInterception. On its own it decrypts nothing — see Decrypting HTTPS.
RulesThe master switch for all rules. The badge counts the active ones.
DeviceNot a switch — it opens the QR and instructions for capturing a phone. The badge counts connected devices.

The alert channel

A line appears between the tiles and the rows only when something needs you. It exists because a tint can say "wrong" but not what is wrong — which app took the system proxy, that the helper is waiting for approval in System Settings, that the network can't reach Loom. Each line carries the repair with it, so it is never a dead end.

Config rows

These are the settings whose state is a phrase rather than a colour, so they keep their words — none, 3 unread, 2 not listening. A › expands the row in place; a ↗ leaves the console.

  • Reverse Proxies — local ports standing in for upstream origins.
  • SSL Scope — which hosts get decrypted, and which ones Loom saw but relayed.
  • Client Certificates — PKCS#12 identities for servers that ask for mutual TLS. Shown only once you have one.
  • Breakpoints — appears while anything is armed or held.

The privileged helper

Blocking QUIC needs root, which would otherwise mean a password prompt every single time you toggle the system proxy. The helper is a small root service you install once and approve in Login Items; after that the toggle is silent.

It is never required. Without it Loom falls back to asking for the password, and the key glyph tells you which state you're in — not installed, waiting for approval in System Settings, or working.

The helper deliberately does not handle certificate trust. Installing a root certificate is machine-wide, so that step stays something you do yourself, with the button or the printed sudo command.

Footer

The version number doubles as the update check. The Loom wordmark opens the main window. Quit exits — and on the way out, if the system proxy still points at Loom, it is switched off, so the machine isn't left routing traffic to a dead port.
